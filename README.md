# Ripple Lab — 水面の波紋シミュレータ

ブラウザ上で動く、インタラクティブな2次元波動シミュレータです。水面をクリック／タップ／ドラッグすると波紋が生まれ、複数の波は重ね合わせの原理に従って干渉します。マルチタッチにも対応しています。

## 開発方針

- **触って理解できること** — 説明を読む前に、水面へ触れるだけで波の伝播・重ね合わせ・反射を観察できるUIにします。
- **物理モデルを単純化しすぎないこと** — 見た目だけの円形アニメーションではなく、格子上で2次元波動方程式を時間発展させます。各入力は同じ波動場へ加算されるため、自然な強め合い・弱め合いが起きます。
- **軽量で配りやすいこと** — ビルドツールや実行時依存を持たないHTML/CSS/JavaScript構成です。静的ホスティングだけで動き、GitHub Pagesに対応します。
- **入力方式を選ばないこと** — Pointer Eventsを用い、マウス、ペン、シングルタッチ、マルチタッチを同じ実装で扱います。
- **段階的に品質を保つこと** — 物理計算と描画を分離し、格子解像度は画面解像度から独立させています。端末性能に左右されにくく、描画サイズだけをレスポンシブに変更します。

## 境界条件

- **OPEN（開放境界）**: 表示領域の外側に48セル幅のスポンジ層を設け、速度項へ滑らかな3次関数の減衰を加えます。その外端ではゾンマーフェルト放射条件の一次離散近似（Mur条件）で進行波を流出させます。スポンジ層を画面外に置くことで、水面の端で波が不自然に薄くなることも防ぎます。
- **REFLECT（反射境界）**: 境界面をまたぐ流束をゼロにする対称な離散ラプラシアンを使い、水槽の壁のように反射させます。各入力直後と各時間ステップ後に画面内の水位の離散積分を補正し、クリック位置・回数や反射回数にかかわらず水の総体積を一定に保ちます。数値誤差でエネルギーが増幅しないよう、微小な壁面損失も加えています。

## ローカル実行

ES Modulesを使うため、任意の静的HTTPサーバーで公開してください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。外部フォントが取得できない環境でもシステムフォントへフォールバックします。

## デプロイ

### GitHub Pages

リポジトリの **Settings → Pages** で、`main` ブランチのルートディレクトリを公開元に指定します。ルート相対URLを使用していないため、プロジェクトページのサブパスでも動作します。

## 操作

- 水面をクリック／タップ: 波源を1つ作る
- 水面をドラッグ: 連続して波源を作る
- 複数の指でタップ: 複数の波源を同時に作る
- OPEN / REFLECT: 境界条件を切り替える
- 波の大きさ: `WaveStrength / SourceSize`を7段階（`20/4`, `30/6`, `40/8`, `50/10`, `60/12`, `70/14`, `80/16`）で同時に調整する
- 一時停止 / 水面をリセット: 時間発展の停止、または波動場の初期化

## 技術メモ

波動場は前フレームと現フレームの2つを保持し、有限差分法で次の状態を求めています。描画では水面の勾配を擬似的な法線として使い、光の濃淡へ変換しています。OPENでは「放射境界条件＋画面外スポンジ層」、REFLECTでは勾配ゼロ条件を用途別に使い分けています。波源には総変位がほぼゼロのRicker型分布を使い、閉じた領域で平均水位が蓄積することを防いでいます。数値発散を避けるため、波動方程式の係数は安定領域に制限しています。
