# Ripple Lab — 水面の波紋シミュレータ

ブラウザ上で動く、インタラクティブな2次元波動シミュレータです。水面をクリック／タップ／ドラッグすると波紋が生まれ、複数の波は重ね合わせの原理に従って干渉します。マルチタッチにも対応しています。

## 開発方針

- **触って理解できること** — 説明を読む前に、水面へ触れるだけで波の伝播・重ね合わせ・反射を観察できるUIにします。
- **物理モデルを単純化しすぎないこと** — 見た目だけの円形アニメーションではなく、格子上で2次元波動方程式を時間発展させます。各入力は同じ波動場へ加算されるため、自然な強め合い・弱め合いが起きます。
- **軽量で配りやすいこと** — ビルドツールや実行時依存を持たないHTML/CSS/JavaScript構成です。静的ホスティングだけで動き、GitHub PagesとCloudflare Workers Static Assetsの双方に対応します。
- **入力方式を選ばないこと** — Pointer Eventsを用い、マウス、ペン、シングルタッチ、マルチタッチを同じ実装で扱います。
- **段階的に品質を保つこと** — 物理計算と描画を分離し、格子解像度は画面解像度から独立させています。端末性能に左右されにくく、描画サイズだけをレスポンシブに変更します。

## 境界条件

- **OPEN（開放境界）**: 外周に近づくほど減衰を強める吸収層を置き、波が領域外へ抜けていく様子を近似します。
- **REFLECT（反射境界）**: 外周の勾配を0にする境界条件を近似し、波を水槽の壁のように反射させます。

## ローカル実行

ES Modulesを使うため、任意の静的HTTPサーバーで公開してください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。外部フォントが取得できない環境でもシステムフォントへフォールバックします。

## デプロイ

### GitHub Pages

リポジトリの **Settings → Pages** で、`main` ブランチのルートディレクトリを公開元に指定します。ルート相対URLを使用していないため、プロジェクトページのサブパスでも動作します。

### Cloudflare Workers

Wranglerをインストール済みの環境で、Cloudflareへログインしてから実行します。

```bash
npx wrangler deploy
```

`wrangler.jsonc` の Assets 設定により、このディレクトリが静的アセットとして配信されます。

## 操作

- 水面をクリック／タップ: 波源を1つ作る
- 水面をドラッグ: 連続して波源を作る
- 複数の指でタップ: 複数の波源を同時に作る
- OPEN / REFLECT: 境界条件を切り替える
- 波の強さ / 波源サイズ: 入力する波の特性を調整する
- 一時停止 / 水面をリセット: 時間発展の停止、または波動場の初期化

## 技術メモ

波動場は前フレームと現フレームの2つを保持し、有限差分法で次の状態を求めています。描画では水面の勾配を擬似的な法線として使い、光の濃淡へ変換しています。数値発散を避けるため係数を安定領域に制限し、微小な減衰を常に加えています。
